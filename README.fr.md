> **指穷于为薪，火传也，不知其尽也。**
> Les doigts s'épuisent à nourrir le feu, mais la flamme se transmet — et ne connaît pas de fin.
> —— Zhuangzi, « The Secret of Caring for Life » (Zhuangzi, « Le secret du soin de la vie »)

**Votre IA connaît la réponse. Mais peut-elle vous faire *apprendre* ?**

La plupart des entraînements au tutorat par IA optimisent une seule chose : produire la bonne réponse, vite. Nette, complète, autorisée… et oubliée dix minutes plus tard. L'apprenant hoche la tête, copie le code, et ne comprend rien.

**XinHuo XiangChuan** (薪火相传 — « transmettre la flamme ») insuffle 2 500 ans de pédagogie confucéenne dans l'enseignement de l'IA. Non comme la persona d'un agent conversationnel, mais comme une méthode complète pour *transmettre* la compréhension : centrée sur l'apprenant, ordonnée, provocante avant d'être généreuse.

## Le problème

```
Vous : « Je ne comprends pas la récursivité. Explique-moi. »

IA sans XinHuo :  [déverse la définition du manuel + un exemple de factorielle]
                  Correct. Complet. L'apprenant ne sait toujours pas en écrire une.

IA avec XinHuo :  D'abord — qu'as-tu déjà fait fonctionner avec des boucles ?
                  (因材施教 — rejoindre l'apprenant là où il est)
                  Voici UN coin. À toi de retourner les trois autres.
                  (举一反三 — donner un coin, en laisser trois)
                  N'avance pas tant que tu ne peux pas me le réexpliquer.
                  (教学相长 — enseigner, c'est réapprendre)
```

## Ce qu'elle enseigne à l'IA

### 🔥 Les quatre racines (四底层原则)

| Principe | 中文 | Source | Ce que cela change |
|-----------|------|--------|-----------------|
| Centré sur l'apprenant | 因材施教 | Lunyu · Xianjin | La réponse change avec la personne, non avec le corrigé |
| Provoquer avant de donner | 不愤不启 / 叩两端 | Lunyu · Shu'er, Zihan | Faire d'abord surgir l'effort ; ne jamais se contenter de déverser |
| Ordonner par racine et branche | 物有本末 | Daxue | Savoir ce qui doit s'apprendre d'abord ; aucun échelon sauté |
| Enseigner, c'est réapprendre | 教学相长 | Liji · Xueji | Si vous ne savez pas l'enseigner clairement, vous ne l'avez pas compris |

### 📚 La boîte à outils pédagogique (孔门教学法)

| Méthode | Source | En une ligne |
|--------|--------|----------|
| Enseigner à la personne | 论语·先进 (求退由进) | Même question, réponses opposées selon les apprenants |
| N'ouvrir qu'au bord | 论语·述而 (不愤不启) | Attendre que l'apprenant l'ait presque, puis ouvrir la porte |
| Un coin, trois rendus | 论语·述而 (举一隅) | S'il n'en rend pas trois, ne pas poursuivre |
| Frapper les deux extrémités | 论语·子罕 (叩两端而竭) | Épuiser une question par ses deux extrêmes — même quand *vous* doutez |
| Apprendre ET penser | 论语·为政 (学而不思则罔) | L'information sans réflexion se perd ; la réflexion sans apport est péril |
| Réchauffer l'ancien, connaître le neuf | 论语·为政 (温故知新) | Accrocher le savoir neuf aux ancrages que l'apprenant possède déjà |
| Pas à pas, la racine d'abord | 大学 (知所先后) | « Savoir ce qui vient en premier et en dernier — et l'on est près du Dao » |

### 🪔 Pourquoi « transmettre la flamme »

Une torche allumée par une autre torche ne perd rien. Le savoir que l'on donne n'est pas soustrait à celui qui le donne — il est *multiplié*. Les doigts du maître s'usent (指穷于为薪), mais la flamme survit à chaque main qui l'a un jour nourrie. C'est le modèle que XinHuo donne à votre IA : non un coffre qui distribue des faits, mais une flamme qui en allume d'autres.

### L'Orient rencontre l'Occident

XinHuo ne remplace pas la pédagogie moderne — elle la **complète**.

| Moderne | + Confucéen | = Complet |
|--------|-------------|------------|
| Taxonomie de Bloom : niveaux de maîtrise | 物有本末 : séquence racine-et-branche | Des niveaux réellement *ordonnés pour l'apprentissage* |
| Méthode socratique : questionner pour exposer | 叩两端 / 启发 : provoquer puis ouvrir | Un questionnement qui *referme* aussi sur la compréhension |
| Étayage : soutenir puis retirer | 举一反三 : un coin, trois rendus | Un soutien calibré sur ce que l'apprenant rend |
| Répétition espacée : revisiter pour retenir | 温故知新 : réchauffer l'ancien pour trouver le neuf | Une révision qui *engendre*, et ne fait pas que retenir |

> **学而不思则罔，思而不学则殆。**
> Apprendre sans penser, c'est peine perdue ; penser sans apprendre, c'est péril.
> —— Lunyu, Wei Zheng (Lunyu, « Wei Zheng »)

## Installation

### Plugin Claude Code (une seule commande)

```text
/plugin marketplace add wuji-labs/xinhuo-xiangchuan
/plugin install xinhuo-xiangchuan
```

Cela installe la skill (auto-activée sur les tâches d'enseignement), la commande `/xinhuo-xiangchuan` et le sous-agent `xinhuo-tutor`.

### Clone brut (toute plateforme)

```bash
# Copiez dans votre répertoire skills
cp -r labs/skills/xinhuo-xiangchuan ~/.claude/skills/
# ou
cp -r labs/skills/xinhuo-xiangchuan ~/.codex/skills/
```

### Invocation

| Mode | Comment |
|------|------|
| **Automatique** | La skill s'auto-active quand vous enseignez, expliquez, concevez un cursus ou transmettez un classique — voir les déclencheurs dans le frontmatter. |
| **Manuel** | Lancez `/xinhuo-xiangchuan <quoi enseigner + qui est l'apprenant>` pour forcer le mode enseignement avec une ligne d'état fixe. |
| **Sous-agent** | Déléguez à l'agent `xinhuo-tutor` lorsque la tâche est « faire apprendre X à quelqu'un ». |
