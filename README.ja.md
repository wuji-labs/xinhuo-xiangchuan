> **指穷于为薪，火传也，不知其尽也。**
> 薪をくべる指は尽きても、炎は受け継がれていく——その終わりを知ることはない。
> —— 庄子《养生主》（荘子「養生主」）

**あなたのAIは答えを知っています。でも、あなたを「学ばせる」ことはできますか？**

ほとんどのAI個別指導の訓練は、ただ一つのことに最適化されています——正しい答えを、速く出すこと。整っていて、完全で、権威がある……そして十分後には忘れられている。学習者はうなずき、コードをコピーし、何も理解していません。

**XinHuo XiangChuan**（薪火相传——「炎を継ぐ」の意）は、二千五百年の孔門師道をAIの教えに注ぎ込みます。チャットボットの人格としてではなく、理解を*伝える*ための完全な方法として——学習者を中心に据え、順序立てて進め、与える前にまず突きつける。

## 問題

```
あなた：「再帰がわからない。説明して。」

薪火なしのAI：  ［教科書の定義 + 階乗の例をそのまま投げ出す］
                正しい。完全だ。それでも学習者は一つも書けない。

薪火ありのAI：  まず——ループで、すでに何が動かせている？
                （因材施教〔人に応じて教える〕——学習者のいる場所で受け止める）
                これが一つの角だ。残りの三つは、君が回してみせて。
                （举一反三〔一角を示し三角を返させる〕——一隅を与え、三隅を残す）
                私に説明し直せるようになるまで、先へ進まないこと。
                （教学相长〔教えることは学び直すこと〕——教えるとは学び直すこと）
```

## AIに何を教えるか

### 🔥 四つの根（四底层原则）

| 原則 | 中文 | 出典 | 何が変わるか |
|------|------|------|--------------|
| 学習者を中心に | 因材施教 | Lunyu · 先進 | 答えは正解集ではなく、人に応じて変わる |
| 与える前に突きつける | 不愤不启 / 叩两端 | Lunyu · 述而、子罕 | まず葛藤を引き出す。決してただ注ぎ込まない |
| 本と末の順序で | 物有本末 | Daxue | 何を先に学ぶべきかを知る。段を飛ばさない |
| 教えることは学び直すこと | 教学相长 | Liji · Xueji | 明快に教えられないなら、理解していない |

### 📚 孔門の教授法（孔门教学法）

| 方法 | 出典 | 一言で |
|------|------|--------|
| 人に応じて教える | 论语·先进（求退由进） | 同じ問いに、学習者ごとに正反対の答えを |
| 際（きわ）でのみ開く | 论语·述而（不愤不启） | 学習者が「あと一歩」になるのを待って、扉を開ける |
| 一隅を与え、三隅を返させる | 论语·述而（举一隅） | 三隅を返せないなら、先へ進まない |
| 両端を叩く | 论语·子罕（叩两端而竭） | 問いを両極から汲み尽くす——*こちら*が確信を持てないときでも |
| 学び、かつ思う | 论语·为政（学而不思则罔） | 省みのない情報は無駄になり、入力のない省みは危うい |
| 故きを温め、新しきを知る | 论语·为政（温故知新） | 新しい知を、学習者の既存の錨に掛ける |
| 一歩ずつ、本を先に | 大学（知所先后） | 「先後の順序を知れば、道に近づく」 |

### 🪔 なぜ「炎を継ぐ」のか

松明から松明へ火を移しても、何も失われません。与えた知識は与え手から差し引かれることなく——むしろ*倍増*します。教える者の、薪をくべる指は尽きます（指穷于为薪）が、炎は薪をくべたあらゆる手よりも長く生き延びます。これこそ薪火があなたのAIに与えるモデルです——事実を払い出す金庫ではなく、ほかの炎を灯す一つの炎。

### 東と西が出会う

薪火は現代の教育学に取って代わるのではなく——それを**完成させ**ます。

| 現代 | + 孔門 | = 完成 |
|------|--------|--------|
| ブルームの分類学：習熟の段階 | 物有本末：本と末の順序 | 本当に「学ぶ順に並んだ」段階 |
| ソクラテス式問答：問いで暴く | 叩两端 / 启发：突きつけてから開く | 開くだけでなく、理解へと*閉じる*問い |
| 足場かけ：支えてから外す | 举一反三：一隅を与え、三隅を返させる | 学習者が返したものに合わせて調整する支え |
| 間隔反復：保持のために再訪する | 温故知新：故きを温めて新しきを得る | 保持するだけでなく、新しきを*生む*復習 |

> **学而不思则罔，思而不学则殆。**
> 学んでも思わなければ徒労に終わり、思っても学ばなければ危うい。
> —— Lunyu · 为政（論語「為政」）

## インストール

### Claude Code プラグイン（一コマンド）

```text
/plugin marketplace add wuji-labs/xinhuo-xiangchuan
/plugin install xinhuo-xiangchuan
```

これで skill（教えるタスクで自動起動）、`/xinhuo-xiangchuan` コマンド、`xinhuo-tutor` サブエージェントがまとめて入ります。

### 素のクローン（任意のプラットフォーム）

```bash
# あなたの skills ディレクトリにコピー
cp -r labs/skills/xinhuo-xiangchuan ~/.claude/skills/
# または
cp -r labs/skills/xinhuo-xiangchuan ~/.codex/skills/
```

### 呼び出し方

| モード | 使い方 |
|------|------|
| **自動** | あなたが教える・説明する・カリキュラムを設計する・古典を伝えるとき、skill が自動起動します——トリガーは frontmatter を参照。 |
| **手動** | `/xinhuo-xiangchuan <何を教えるか + 学習者は誰か>` を実行すると、固定のステータス行つきで教えるモードを強制します。 |
| **サブエージェント** | 仕事が「誰かに X を学ばせる」ときは、`xinhuo-tutor` エージェントに委ねます。 |
