> 땔감을 더하는 손가락은 다하여도, 불은 이어져 간다——그 끝을 알지 못한다.
> —— 庄子《养生主》(장자 「양생주」)

**당신의 AI는 답을 압니다. 하지만 당신을 *배우게* 할 수 있습니까?**

대부분의 AI 튜터링 학습은 단 한 가지에 최적화됩니다——정답을, 빠르게 내놓는 것. 깔끔하고, 완전하고, 권위 있게…… 그리고 십 분 뒤면 잊힙니다. 학습자는 고개를 끄덕이고, 코드를 복사하고, 아무것도 이해하지 못합니다.

**XinHuo XiangChuan**(薪火相传——"불씨를 잇다"의 뜻)은 이천오백 년의 공문(孔門) 사도(師道)를 AI의 가르침에 불어넣습니다. 챗봇 페르소나로서가 아니라, 이해를 *전하는* 완전한 방법으로서——학습자를 중심에 두고, 차례를 좇아 나아가며, 베풀기에 앞서 먼저 들이댑니다.

## 문제

```
당신: "재귀를 모르겠어. 설명해 줘."

불씨 없는 AI:  ［교과서 정의 + 팩토리얼 예제를 그대로 쏟아낸다］
                정확하다. 완전하다. 그래도 학습자는 하나도 못 짠다.

불씨 있는 AI:  먼저——반복문으로 이미 무엇을 돌려봤나?
                （因材施教〔사람에 맞춰 가르치다〕——학습자가 선 자리에서 받아준다）
                여기 한 귀퉁이가 있다. 나머지 셋은, 네가 돌려 보라.
                （举一反三〔하나를 들면 셋을 돌려받다〕——한 귀퉁이를 주고, 세 귀퉁이를 남긴다）
                내게 다시 설명할 수 있기 전엔, 앞으로 나아가지 말 것.
                （教学相长〔가르침은 다시 배움〕——가르치는 것은 다시 배우는 것）
```

## AI에게 무엇을 가르치는가

### 🔥 네 가지 뿌리 (四底层原则)

| 원칙 | 中文 | 출전 | 무엇이 바뀌는가 |
|------|------|------|--------------|
| 학습자 중심 | 因材施教 | Lunyu · 선진(先進) | 답은 정답집이 아니라 사람에 따라 달라진다 |
| 베풀기에 앞서 들이대다 | 不愤不启 / 叩两端 | Lunyu · 술이(述而), 자한(子罕) | 먼저 그 분투를 끌어낸다. 결코 그저 들이붓지 않는다 |
| 근본과 말단의 순서로 | 物有本末 | Daxue | 무엇을 먼저 배워야 하는지 안다. 단을 건너뛰지 않는다 |
| 가르침은 다시 배움 | 教学相长 | Liji · Xueji | 명료하게 가르치지 못하면, 이해하지 못한 것이다 |

### 📚 공문 교수법 (孔门教学法)

| 방법 | 출전 | 한 줄 |
|------|------|--------|
| 사람에 맞춰 가르치다 | 论语·先进（求退由进） | 같은 물음에, 학습자마다 정반대의 답을 |
| 벼랑 끝에서만 열어 주다 | 论语·述而（不愤不启） | 학습자가 거의 깨칠 때를 기다려, 그제야 문을 연다 |
| 한 귀퉁이를 주고 셋을 돌려받다 | 论语·述而（举一隅） | 세 귀퉁이를 돌려주지 못하면, 앞으로 나아가지 않는다 |
| 양 끝을 두드리다 | 论语·子罕（叩两端而竭） | 물음을 양극단에서 캐낸다——*내가* 확신이 없을 때조차 |
| 배우고, 또한 생각하다 | 论语·为政（学而不思则罔） | 성찰 없는 정보는 헛되고, 입력 없는 성찰은 위태롭다 |
| 옛것을 익혀 새것을 알다 | 论语·为政（温故知新） | 새 지식을 학습자의 기존 닻에 건다 |
| 한 걸음씩, 근본을 먼저 | 大学（知所先后） | "먼저와 나중을 알면 도에 가깝다" |

### 🪔 왜 "불씨를 잇다"인가

횃불에서 횃불로 불을 옮겨도, 잃는 것은 없습니다. 내어 준 지식은 준 이에게서 덜리지 않고——오히려 *배가됩니다*. 가르치는 이의, 땔감을 더하는 손가락은 다하지만(指穷于为薪), 불은 땔감을 더했던 모든 손보다 오래 살아남습니다. 이것이 바로 薪火가 당신의 AI에게 주는 모델입니다——사실을 내어 주는 금고가 아니라, 다른 불을 밝히는 하나의 불.

### 동과 서가 만나다

薪火는 현대 교육학을 대체하지 않습니다——그것을 **완성**합니다.

| 현대 | + 공문 | = 완성 |
|------|--------|--------|
| 블룸의 분류법: 숙달의 단계 | 物有本末: 근본과 말단의 차례 | 정말로 "배우는 순서대로 놓인" 단계 |
| 소크라테스식 문답: 물음으로 드러내다 | 叩两端 / 启发: 들이댄 뒤 연다 | 열기만 하는 게 아니라, 이해로 *닫히는* 물음 |
| 비계(scaffolding): 받쳤다가 거둔다 | 举一反三: 한 귀퉁이를 주고 셋을 돌려받다 | 학습자가 돌려준 것에 맞춰 조정하는 받침 |
| 간격 반복: 유지하려 다시 찾는다 | 温故知新: 옛것을 익혀 새것을 얻다 | 유지만이 아니라 새것을 *낳는* 복습 |

> **学而不思则罔，思而不学则殆。**
> 배우되 생각하지 않으면 헛수고요, 생각하되 배우지 않으면 위태롭다.
> —— Lunyu · 为政 (논어 「위정」)

## 설치

### Claude Code 플러그인 (한 줄 명령)

```text
/plugin marketplace add wuji-labs/xinhuo-xiangchuan
/plugin install xinhuo-xiangchuan
```

이것으로 skill(가르치는 작업에서 자동 활성화), `/xinhuo-xiangchuan` 명령, `xinhuo-tutor` 서브에이전트가 한꺼번에 설치됩니다.

### 맨 클론 (모든 플랫폼)

```bash
# 당신의 skills 디렉터리에 복사
cp -r labs/skills/xinhuo-xiangchuan ~/.claude/skills/
# 또는
cp -r labs/skills/xinhuo-xiangchuan ~/.codex/skills/
```

### 호출 방식

| 모드 | 사용법 |
|------|------|
| **자동** | 당신이 가르치거나, 설명하거나, 커리큘럼을 설계하거나, 고전을 전할 때 skill이 자동 활성화됩니다——트리거는 frontmatter 참조. |
| **수동** | `/xinhuo-xiangchuan <무엇을 가르칠지 + 학습자는 누구인지>`를 실행하면, 고정 상태 줄과 함께 가르치는 모드를 강제합니다. |
| **서브에이전트** | 작업이 "누군가에게 X를 배우게 하기"일 때는 `xinhuo-tutor` 에이전트에 위임합니다. |
