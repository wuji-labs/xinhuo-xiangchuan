> **指穷于为薪，火传也，不知其尽也。**
> Os dedos se esgotam ao alimentar o fogo, mas a chama é passada adiante — e não conhece fim.
> —— Zhuangzi, «The Secret of Caring for Life» (Zhuangzi, "O segredo do cuidado com a vida")

**Sua IA sabe a resposta. Mas será que ela consegue fazer você *aprender*?**

A maior parte do treinamento de tutoria com IA é otimizada para uma única coisa: produzir a resposta certa, rápido. Limpa, completa, autoritativa... e esquecida dez minutos depois. O aprendiz acena com a cabeça, copia o código e não entende nada.

**XinHuo XiangChuan** (薪火相传 — «passar a chama») infunde 2500 anos de pedagogia confuciana no ensino da IA. Não como a persona de um chatbot, mas como um método completo para *transmitir* a compreensão: centrado em quem aprende, sequenciado, provocador antes de ser generoso.

## O problema

```
Você: «Não entendo recursão. Explica.»

IA sem XinHuo:   [despeja a definição do livro-texto + um exemplo de fatorial]
                 Correta. Completa. O aprendiz ainda não sabe escrever uma.

IA com XinHuo:   Primeiro — o que você já tem funcionando com laços?
                 (因材施教 — receba o aprendiz onde ele está)
                 Aqui está UM canto. Agora vire você os outros três.
                 (举一反三 — dê um canto, deixe três)
                 Não siga em frente até conseguir me explicar de novo.
                 (教学相长 — ensinar é reaprender)
```

## O que ela ensina à IA

### 🔥 As quatro raízes (四底层原则)

| Princípio | 中文 | Fonte | O que muda |
|-----------|------|--------|-----------------|
| Centrado em quem aprende | 因材施教 | Lunyu · Xianjin | A resposta muda com a pessoa, não com o gabarito |
| Provocar antes de dar | 不愤不启 / 叩两端 | Lunyu · Shu'er, Zihan | Faça emergir primeiro o esforço; nunca apenas despeje |
| Sequenciar por raiz e ramo | 物有本末 | Daxue | Saber o que precisa ser aprendido primeiro; sem degraus pulados |
| Ensinar é reaprender | 教学相长 | Liji · Xueji | Se não consegue ensinar com clareza, não entendeu |

### 📚 Caixa de ferramentas pedagógicas (孔门教学法)

| Método | Fonte | Em uma linha |
|--------|--------|----------|
| Ensinar à pessoa | 论语·先进 (求退由进) | A mesma pergunta, respostas opostas para aprendizes diferentes |
| Abrir só à beira | 论语·述而 (不愤不启) | Espere o aprendiz quase chegar lá, e então abra a porta |
| Um canto, três devolvidos | 论语·述而 (举一隅) | Se não devolverem três, não prossiga |
| Bater nas duas extremidades | 论语·子罕 (叩两端而竭) | Esgote uma pergunta pelos dois extremos — mesmo quando *você* está incerto |
| Aprender E pensar | 论语·为政 (学而不思则罔) | Informação sem reflexão é desperdiçada; reflexão sem insumo é perigo |
| Aquecer o velho, conhecer o novo | 论语·为政 (温故知新) | Pendure o saber novo nas âncoras que o aprendiz já tem |
| Passo a passo, a raiz primeiro | 大学 (知所先后) | «Saiba o que vem primeiro e por último — e estará perto do Dao» |

### 🪔 Por que «passar a chama»

Uma tocha acesa por outra tocha nada perde. O conhecimento que se dá não é subtraído de quem dá — é *multiplicado*. Os dedos do mestre se gastam (指穷于为薪), mas a chama sobrevive a cada mão que um dia a alimentou. Este é o modelo que XinHuo dá à sua IA: não um cofre que dispensa fatos, mas uma chama que acende outras chamas.

### O Oriente encontra o Ocidente

XinHuo não substitui a pedagogia moderna — ela a **completa**.

| Moderno | + Confuciano | = Completo |
|--------|-------------|------------|
| Taxonomia de Bloom: níveis de domínio | 物有本末: sequência de raiz e ramo | Níveis de fato *ordenados para aprender* |
| Método socrático: perguntar para expor | 叩两端 / 启发: provocar e então abrir | Um perguntar que também *fecha* em compreensão |
| Andaime: apoiar e então retirar | 举一反三: um canto, três devolvidos | Apoio calibrado pelo que o aprendiz devolve |
| Repetição espaçada: revisitar para reter | 温故知新: aquecer o velho para achar o novo | Revisão que *gera*, não apenas retém |

> **学而不思则罔，思而不学则殆。**
> Aprender sem pensar é trabalho perdido; pensar sem aprender é perigoso.
> —— Lunyu, Wei Zheng (Lunyu, «Wei Zheng»)

## Instalação

### Plugin do Claude Code (um único comando)

```text
/plugin marketplace add wuji-labs/xinhuo-xiangchuan
/plugin install xinhuo-xiangchuan
```

Isso instala a skill (autoativa em tarefas de ensino), o comando `/xinhuo-xiangchuan` e o subagente `xinhuo-tutor`.

### Clone direto (qualquer plataforma)

```bash
# Copie para o seu diretório de skills
cp -r labs/skills/xinhuo-xiangchuan ~/.claude/skills/
# ou
cp -r labs/skills/xinhuo-xiangchuan ~/.codex/skills/
```

### Invocação

| Modo | Como |
|------|------|
| **Automático** | A skill se autoativa quando você ensina, explica, projeta um currículo ou transmite um clássico — veja os gatilhos no frontmatter. |
| **Manual** | Execute `/xinhuo-xiangchuan <o que ensinar + quem é o aprendiz>` para forçar o modo de ensino com uma linha de status fixa. |
| **Subagente** | Delegue ao agente `xinhuo-tutor` quando a tarefa for «fazer alguém aprender X». |
